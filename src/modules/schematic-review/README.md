# 示意图审核模块

顶部顺序：生成示意图 → 示意图审核 → 生产拼版。

本目录维护示意图导出记录的列表、搜索和恢复编辑。PDF、SVG、PNG、JPG 成功导出后，前端将本次导出的排列快照交给 Rust，保存到应用数据目录的 `printflow.sqlite` 中的 `schematic_reviews` 表。取消或导出失败不会新增记录。

打开顶部“示意图审核”可按客户或文件名搜索记录，点击“编辑”回到示意图排列页。恢复内容包含全部页面、图片位置、备注、工艺文字、标尺调整、视觉缩放、小数位数及页面配置；继续修改并导出会新增记录，保留原记录。

审核记录可通过“拼版”选择已付款或未付款后进入生产拼版，待拼版期间禁止编辑和删除。在生产拼版的待拼版列表点击“回退”并确认后，该单回到示意图审核，状态显示“被退回”，恢复编辑、删除和再次发起拼版的入口。回退保留付款信息与原始快照；再次提交后状态恢复为待拼版。回退状态持久化在生产任务的 `status` 字段中，回退和再次提交由数据库事务保护。

保存记录失败会单独提示，并提供“重试保存记录”，无需再次导出文件。此功能启用前导出的文件没有排列快照，需要重新导出才能出现在列表中。

- `index.ts`：对外导出模块标识和页面。
- `SchematicReviewPage.tsx`：模块页面入口。
- `schematic-review.css`：以模块类名前缀限定的页面样式。
- `reviewRecords.ts`：快照数据结构、导出后保存以及 Rust 命令接口。
- `src-tauri/src/schematic_review.rs`：独立图片内容和排列快照的 SQLite 持久化，以及轻量列表读取。

`App.tsx` 负责模块注册、显示切换、导出后通知列表刷新，以及将选定快照传入示意图页面。模块通过明确的数据接口交互，不直接访问另一模块内部状态。

沿用应用的首次访问挂载机制：访问后切换模块保留挂载，页面状态得以保留。
