# 示意图排列规则（2026-09-19 重写版）

此版本替代旧版动态列数、自动放大与手动表头位置规则，不恢复旧版排列状态。前页回填采用下文的整组平移规则，不使用旧版缩放算法。源 SVG、上传图片与产品属性保持独立。

## 基础布局

- `arrangement/threeColumnLayout.ts` 是生成、自动排列、组合重排、图片池加图、区域变更的布局入口。
- 普通图片固定三列，每列包含图片和属性。组间保留 1.8mm 留白；放不下则下一页。
- 表头高度 26 画布单位，背景 #B5D5BE；位置、列数自动确定，不能拖动。属性标题仍可编辑。
- 默认下边距 10mm，上边距沿用 40mm。画布宽 500 对应纸张 210mm，不将画布数值误认为毫米。
- 默认显示以充分利用图片区、保证小图清晰为主。先按各组可用图片区计算放大上限，再对当前页同产品的主图与派生背面统一视觉最长边参考（按 productKey 识别，不区分单面/双面布局）。同样的真实尺寸显示等大，接近的尺寸视觉接近，真实最长边较小的图不会因所在块更宽而显示得更大。不同产品及其他页面独立计算，未选择产品的图片仍仅在本组内比较。原始物理尺寸优先取有效 sourceGroupWidthMm/HeightMm；无有效物理数据时按 SVG 用户单位的 CSS px 回退。各图权重为 `max(0.7, sqrt(真实最长边 / 当前页同产品最大真实最长边))`，参考最长边取各图可容纳最长边除以权重后的最小值，尽量用满最受限的图片区。当前页同产品最大尺寸为 80 mm 时，40 mm 与 80 mm 的同形图片约显示为 71:100；42.6 mm 与 43.1 mm 视觉接近；极小图至少保留参考最长边的 70%。允许放大到超过纸张 1:1，每张图自身宽高比不变，视觉比例不等同于实际毫米比例。底座、配件和备注图片仍在各自区域独立适配。手动视觉缩放仍作为用户覆盖，源尺寸、Size 和标尺数值不变。
- 左侧图片和尺寸线预留内缩空间。
- 立牌主图以原适配大小的 120% 为默认显示目标，受单元格剩余宽高限制；收紧左右留白，左侧保留 8 单位，右侧可贴到属性区边界。当前页同产品共用视觉大小参考，正反面保持等大、图片垂直居中；底座不额外放大，真实尺寸及主图高度扣减 3.4 mm 的规则不变。
- 初次分页后尝试前页回填：优先填补兼容表头下的空列，再使用页面底部余量；可以跳过放不下的大组，从后页选取能完整容纳的小组。整组平移，不缩放、不拆组、不改变组内顺序。
- 回填不同列结构时必须预留新表头高度及组间距，所有图片、标尺单元与属性区同步移动；移除无内容的表头和空页，重新编号。
- 双面不同图立牌占左侧两列时，右侧第三列独立参与补位：优先从本页后续区域，再从后续页选取能完整放下的单列组。右列保留自己的表头（如 `photo`），切换表头模式时预留表头高度；只移动组、图片、属性与标尺单元，不缩放或拆组。超高或跨列组不强塞。表头归属同时检查横向范围和纵向位置，收紧及删除操作分别维护左右区域。
- 后页图片组被前移后，原页按表头区段收紧：首个表头回到排列区域顶部，删除整行空隙，同一行的剩余组从第一列开始。图片、属性和标尺单元同步平移，不缩放、不改变组内排列；没有立牌的页面，页底不足一组的余量仍可留白。
- 立牌（Standees）行的内容区高度固定为可排列区域高度的三分之一，不包含上方表头与组间隔。初始分页就预留该高度，同一行的单列组与双列组共用完整行高；多主图在这一固定高度内分配单元格。其他产品放不下时换页，不压缩立牌行。分页与补位后不再将剩余空白分给立牌行，空白保留。其他产品行保持原高度；主图按同页同产品视觉大小规则在单元格内垂直居中，底座独立适配，工艺文字保持在组底部。各页独立计算，自定义边距、重新排列及导出共用结果；贴纸保护规则保持生效。

## 排列后空闲区域检查

基础分页和前页回填后执行 `arrangement/freeRegionPacking.ts` 的 `fillFreeRegions`，最后通过 `arrangement/physicalImageSizing.ts` 按各组空间适配、校准同页同产品视觉大小并垂直居中；立牌行保留分页时确定的三分之一高度，不按页底余量拉伸。`findFreeRegions`（`arrangement/freeRegions.ts`）从排列区域扣除图片组实际背景占位、表头、未归组图片的旋转包围盒及 1.8mm 间距，返回候选空矩形。候选矩形之间可能重叠，每次填入后必须重新检测，不能把结果一次性当作独立格子使用。

同一表头行在产品切换时如果留下空列，空列保持空白，不跨产品补位；后续补位只允许与该行已有图片组使用相同产品标识的图片进入，优先保持同一种产品连续排列。新产品开始的行仍可接收同产品的后续图片。

同种立牌产品按三列基础网格连续排列：同图组占 1 列，异图组占 2 列，允许 `1＋2` 或 `2＋1` 共用一行；剩余列数容纳不下完整组时才换行。混合行共用一个表头，每组仅有一份图片标题和属性标题，标题宽度按该组占列数对齐。分页先预留整行的固定三分之一高度；后续跨页、侧列和空白补位不拆散已排好的混合行。不同产品仍不混排，贴纸保护规则保持生效。

进入示意图排列页及“产品排序”模式使用产品、印刷选项分类顺序；没有产品标识的图片统一排在所有已配置产品之后，并保持其原始相对顺序。

产品名包含 `Stickers`、`Sticker` 或 `贴纸` 时，该产品在生成顺序中优先排在最前。包含贴纸组的页面保留空白位置，不参与其他产品的跨页、空闲区域或侧列补齐；贴纸组本身也不会被移动去补齐其他产品页面。

填充优先检查靠上、靠左的空位，再按本页后续位置及后页顺序寻找完整容纳的组；大组放不下可跳过。匹配现有表头时复用其列位置，否则计入独立表头高度和间距，且不能改变已有组的表头归属。空位若已经属于现有表头区段，或位于现有表头下方的同一行，不再创建嵌套/并排的第二个表头；只有新的区段才允许创建表头。只将已排版的整组前移，保持图片尺寸、组内关系、属性和标尺偏移，不从未使用图片池自动取图。每次移动后继续检测，直到没有可前移的组；清理无内容的自动表头、空页并重新编号。初次生成、排序切换及其他自动重排均通过同一入口执行。

## 标尺

- 所有产品的左侧高标尺在原位置基础上整体向左偏移 2 个画布单位，文字、箭头和延长线起点同步移动；原基准位置为组左边界内缩 8 单位与图片左边缘外侧 2 单位中较靠右的位置。该调整不按产品名称区分，图片移动、视觉缩放后继续保留；画布与导出共用位置计算，不改变主图大小、位置或尺寸数值。
- 默认显示原始最长边。Size 有值时换算为最长边的毫米值，另一边按原始宽高比计算。
- 单图支持 mm/cm/in，换算基于未舍入的物理尺寸；工具栏的小数位数输入与默认值、四舍五入、舍弃小数及单位选择联动。默认值按当前位数保留原始值，不做四舍五入；可对框选图片一起设置并保留为画布显示覆盖，只改变显示文字，不写回原始尺寸。
- 宽、高开关独立，默认最长边对应开关开启。生成背面和指定的无标尺角色不可开启。
- Size 属性文字与该图最长边标尺使用同一换算函数。
- 自动重排保留单位及宽高开关。
- 导出 PDF、SVG、PNG、JPG 时携带各图片的显示设置；Size 和标尺使用与画布相同的小数位数及取整方式，0 位不可回退为默认 1 位。多页导出包含所有已设置图片，不依赖当前选择，仅生成显示副本，不改原始尺寸。
- 选择模式可拖拽框选当前页面的图片，支持任意拖动方向，矩形与图片相交即选中；框选在当前缩放和平移位置下换算为纸张坐标。拖动不移动图片，平移模式或按住空格时不触发框选。
- 框选可批量修改 mm/cm/in、宽标尺和高标尺，并同步每个成员的 Size；两轴分别修改，保留每张图片另一轴的当前或默认状态。禁止标尺的背面/角色继续跳过。混合单位及部分勾选状态在工具栏显示。
- 框选与 Ctrl 组合选组相互独立：框选不限两组，组合仍最多两组且可跨页；切页或重新排列清除框选。组数提示紧跟“组合”，不同工具功能用竖分割线隔开。
- 选择模式中选中图片组后按 Delete，将整组（包括派生背面）移出画布并归入未使用图片池；框选时按完整组处理。只删除排版引用，不删除上传资源、产品属性或历史数据，不自动重排其他组。输入框或弹窗内不响应此快捷键。
- 排列页属性面板禁止手动和自动进入图片组合引导，上传页引导保持可用。排列图片池保留“全部 / 未使用”，默认未使用，取消“已排版”切换标签。
- 图片池卡片双击加入画布，放大预览使用独立放大镜按钮，单击图片不弹出预览。全部标签下的未使用图片也可加入；已使用图片禁止重复添加。
- 内部图片拖动采用 Pointer Capture，避免桌面原生文件拖放拦截 HTML 拖动；超过 5px 开始拖动，松手时按画布缩放和平移换算落点，仅纸张范围内添加。取消拖动或释放在纸张外不添加，上传页原生文件拖放保持不变。

## 特殊产品

- 摇摇乐（Shaker）使用同页同产品的视觉大小参考，允许小图放大以充分展示，保留半页高度及 Example / Front / Inside / Back 和其余成员布局。

1. Photocard Holders / Shaker：表头高度＋表头下间隔＋产品组高度＋组后间隔合计占排列区域高度 50%，整行；组高度为排列区域高度的一半减去表头高度和两个组间隔。相邻组复用表头时不重复绘制，但仍按该预算计算组高度。第一行 Example 加标尺；第二行 Front / Inside / Back 不加标尺；剩余图片第三行（多图可在该区域换行），每图有标尺。按图片属性值/名称识别角色，缺少角色信息时按组内顺序填充。右侧是属性区。
   当固定槽位中的 Example 为空时，不保留空占位：Front、Inside、Back 直接进入 Example 区域，在扣除右侧属性栏后的图片区内三等分，使用同页同产品视觉大小规则并在上半区各自单元格内居中；仅 Front 显示标尺，Inside 和 Back 不显示标尺。Example 有内容时继续使用上面的原布局。
2. 普通双面不同图：同一原图生成水平镜像背面，Front/Back 上下排列，只有 Front 有标尺。
3. Standees / 立牌：自动表头使用 `Front/Back`。每个成员独立判断印刷选项；同图显示一次，不同图左右展示正反面，图片旁不重复显示 Front/Back 标签。非底座成员中只要存在双面不同图，整组宽度占三列基础网格中的两列（含两列之间的间距），只保留一份右侧属性区，表头与组宽对齐；同图立牌保持单列。多图组最后一张作为底座，固定放在右侧属性列的下方，属性文字区域和底座不重叠；底座使用独立的小写 `base` 红色标识，字号小于普通角色标识并左对齐，在属性列剩余空间内等比放大到可用上限。仅底座为双面不同图不触发跨列。单张立牌不当成底座。初次排列、排序切换和跨页补位均保留该宽度；补位必须匹配表头宽度和模式，不将跨列立牌塞进单列或 photo 表头下。
4. 串串：全部为双面同图的组使用三列布局，每行最多三组；组中包含双面不同图时使用两列布局，每行最多两组，表头对应实际列数。每列均包含该组图片区与属性区。成员仍按组内顺序纵向逐件排列，每图按自身印刷选项确定是否增加右侧镜像背面，正反面左右对应且等大；属性区按成员顺序列出全部 Size（相同尺寸也保留，不重复列出派生背面），切换单位及重排时同步更新。最终显示使用同页同产品的视觉最长边参考，压缩真实尺寸差异，兼顾清晰度与大小区分；接近的尺寸视觉接近，较小图不低于参考最长边的 70%。名称识别支持串串、串联、串連、chained、linked charm、connecting charm。

## 背面层预览（试运行）

串串组中只要有双面不同图成员，图片区固定分为两列：第一列正面、第二列背面，每个成员独占一行，下一个成员放到下一行。同组双面同图成员仍对齐第一列，第二列留空；全部为双面同图时使用单列纵排。每对正反面使用相同的单元宽高和缩放比例。

串串行高按当前适配后的图片高度加标尺和底部留白计算，取消每个成员固定占 120 单位的空白；组高取图片总高度与属性文字、配件和备注所需高度的较大值。收紧留白时不进一步缩小图片，Photocard Holders / Shaker 的半页规则保持不变。

双面不同图以 SVG 标签顺序的第一张 `<image>` 为背面来源，不按图层名称判断。从后向前完整删除后续 `<image>` 元素，保留第一张图片、父组、裁剪、defs、变换与轮廓路径；不修改原文件。背面 SVG 内不额外镜像，画布、缩略图和导出通过 Item.mirrorX 整体水平翻转一次。正反面图片缓存按各自实际 SVG 内容区分。
5. 特殊产品按 productGroupId 和 productGroupPosition 确定组及顺序。普通图片不恢复旧版自由产品组的动态布局；显式“组合”仍形成一个组。

## 渲染与导出

- 排列区域在画布及 SVG、PNG、JPG、合并 PDF 导出中均显示中性灰色的外侧浮动阴影和同尺寸的圆角边框；阴影衬底位于图片和文字下方，圆角边框位于内容上方，不拦截选择和拖动。边框与阴影使用当前排列边距，不按图片实际占用范围缩短；空白区域及空页也保留完整效果。导出仅对独立阴影层模糊处理，边框使用无填充的矢量线条，图片和文字不受阴影滤镜影响。

- 工艺名称读取时跳过纯数字标记（例如 `1`），继续读取有效的工艺/Finish/表面名称；组内汇总不得将数量或数字标记拼入红色工艺文字。
- 摇摇乐与照片夹的前四个角色如果原始尺寸全部为高大于宽，则扣除右侧属性栏后，在剩余图片区使用一行四等分，并按同页同产品视觉大小规则在各自单元格内居中；只要有一个不是竖图，就沿用 Example 上方、Front/Inside/Back 下方的现有布局。每个成员的备注跟随对应图片显示在图片下方，并为备注预留高度。

- 展开源 SVG 必须通过 XML 根节点提取内容，排除 XML 声明、DOCTYPE 和文档级注释，保留根节点声明的命名空间；禁止通过第一个 `>` 截取正文，避免 CorelDRAW 文件导致 PDF 页面 XML 解析错误。

- PDF 页面逐页生成并等待暂存完成，再生成下一页；WebView 不保留全部页面的大字符串数组。选择 PDF 文件后，Rust 只写入一个包含全部页面的合并多页 PDF，不再生成 `1.pdf`、`2.pdf` 等单页文件。成功或失败均清理本次导出的临时页面，原始图片不受影响。临时文件标识仅允许十六进制和连字符，不接受任意路径。

- PDF 进度区分配件准备、页面生成、传输、资源加载、SVG 展开、字体准备、解析、矢量转换和写盘；不再将第一页完成前的全部等待统称“准备页面”。前端逐页生成时让出事件循环，进度可以刷新。
- 展开嵌入 SVG 时已有有效 viewBox 就直接读取坐标，不重复调用 usvg 解码整个图像；无 viewBox 时保留解析获取尺寸的回退。

- 合并 PDF 默认文件名采用批次第一份上传大图 SVG 的原文件名，仅替换为目标扩展名。sourceFileName 随图片持久化；旧批次回退为拆图名称的原文件名前缀，无信息时使用“示意图”。

- 派生背面仅是展示项，标记 derivedFrom/mirrorX，不新增上传资源。
- Canvas 与 SVG/JPG/PNG/PDF 共用布局、镜像、角色标签和尺寸计算。
- 串串产品组最后一张之前的 SVG，高标尺保持原上端位置，下端改为 SVG 内图片的最低点，避开图片下方挂孔等轮廓留白。串串最后一张（含单张组）保留原完整高度标尺；成员按 productGroupPosition 排序，旧记录按组内 itemIds 顺序判断，拖动位置不改变顺序，派生背面不另算成员。按图片位置、父级变换和原始像素比例计算；多图取最低边，派生背面按自身 SVG 计算。只改变标尺锚点，不修改真实宽高、Size 或标尺数值；宽标尺与其他产品保持原规则，无有效图片时回退原边界。手动标尺范围仍按锚点比例随移动、视觉缩放更新，画布与导出一致。
- 名称包含立牌或 Standee/Standees 的产品不使用图片底部锚点规则。主图高度的默认显示值扣除 3.4 mm，Size 选用高度时与高标尺数值同步；高标尺上端不动，下端按扣减后的高度比例缩短。先扣减毫米值，再换算单位和应用小数位数，原始宽高与资产属性不变。宽度和标记为 `base` 的底座所有尺寸不扣减。手动调整、图片移动、视觉缩放及导出共用同一计算，仍允许将下箭头拖回原完整高度的最低点。
- 图片底部只作为高标尺的默认下端位置，不限制拖动上限；下箭头可继续向下移动到原完整高度的最低点，并可再次缩短。调整值仍相对原默认锚点保存（向下延伸后结束比例可大于 1），重新显示、图片移动、视觉缩放和导出均保留该位置；初始未调整的标尺文字保持不可拖动。
- 画布点击主图只选择该图片，点击配件或备注图片只选择对应资源；图片、配件和备注图的缩放与拖动状态相互独立，主图拖动不会带动配件。
- 右侧“图片属性”面板在选中单图、整组或框选组内图片/备注区域时提供缩小按钮、百分比输入和放大按钮。该比例只存在于画布显示状态，主图缩放会同步调整主图标尺但不改变 Item 的真实尺寸、位置或排版数据；配件/备注图使用各自独立的缩放比例，清除回 100% 即恢复原显示。
- 备注按英文/数字单词和中文字符分别换行，单词不会被拆成两行；工艺/Finish 标签保留在组底部，布局会为备注预留底部空间，备注始终位于工艺之上。
- 属性配件仍只读 attributeImages['Accessories Color']，其他属性/备注逻辑沿用独立服务。
- 与当前规则不兼容的四份 `.legacy.mjs` 排列测试已清理，历史版本可从 Git 查看；当前排列回归入口为 `tests/three-column-layout.test.mjs`。名称包含 legacy 的有效历史数据兼容测试仍保留。



- 属性区 Size 与 QT 使用相同字号、相同粗体，不单独缩小 Size；数字与单位保持同一行。排版时按当前批次最长 Size（含 mm/cm/in 三种换算）预留属性区宽度，Canvas 与导出共用字体尺寸。极窄排列区域无法容纳图片和完整文字时提示增大宽度。
- QT 允许为空或为 0；画布属性区仍显示 `QT:` 标题，但不显示连字符或 0。
- 隐藏属性区的 Accessory: 标题，配件图片、白底及编号保持显示；表头字段名保持不变。

- 自动排列工具栏直接显示当前排序方式，点击排序文字按钮在“默认顺序”和“上传顺序”之间切换，不使用下拉框。默认顺序按当前页面中已确认的产品/印刷排列顺序，上传顺序按批次资产顺序。

- 所有图片在各自可用单元格内垂直居中，包括普通单图、立牌主图/底座、多图、双面图、串串和带角色的图。上方为标尺或角色文字留白，下方为备注与工艺留白；单图通常上下各留 14 单位，有 Finish 时底部至少留 16 单位。标尺跟随最终图片位置，原始尺寸文字不变。横向标尺两端使用图片实际左右边缘；延长线与对应图片边缘对齐。

- 图片属性区始终以图片组右边界为基准自适应：旧数据中的 detailsX/detailWidth 会被限制在组内，属性文字、配件图和备注不会越过右边界。
- 立牌双面不同图的背面保留第一张 authored image，并按该图片的原始 x/y/width/height 裁剪背面 SVG 视口；因此正反面在同一组内使用一致的视觉尺寸。普通产品和串串的背面提取规则不变。
- 配件图片加载完成后先计算透明/近白边界，再绘制白色衬底；衬底只比裁剪后的可见配件扩大 2 个单位，不能使用原始图片的大白色画布作为衬底尺寸。

- 远程配件图不直接由 WebView 跨域加载：桌面版通过 Rust etch_remote_image 转 data URL，Vite 开发环境通过 __printflow_remote 同源代理；两条路径统一进入白边裁剪。远程响应限制为图片类型且不超过 12 MB。

- 普通单图组不论横图、竖图还是正方形，均取消图片区右侧额外 5 单位留白，并在收回留白后的可用区域重新计算水平中心，使图片在宽度允许时放大到属性栏边界；保留左侧标尺留白、属性文字内边距和上下高度限制，宽高比不变。较高图片受到高度限制时允许右侧留白。多图角色的列布局和组内大小差异规则保持不变，立牌仍使用自己的左右留白规则。
照片夹（Photocard Holders / 照片夹）使用同页同产品视觉大小规则，允许小图放大；Example、Front、Inside、Back 保留适度的大小差异及各自宽高比。双面不同图派生正反面使用相同的最终比例。
照片夹和摇摇乐的前四个主图建立组内视觉基准；后续图片在真实物理最长边不超过前四个主图最大值时，不得显示得更大，真实物理尺寸更大的后续图片可按视觉大小规则显示得更大。
照片夹与摇摇乐（Shaker）Front / Inside / Back 行均按整组宽度三等分，各图片水平居中；该行不再为右侧属性预留空列。属性、配件和备注限制在上方 Example 行右侧，防止覆盖 Back。摇摇乐也按同页同产品视觉大小规则充分展示小图。
取消配件 40px→30px 阈值：配件可见宽度限制为当前配件显示槽尺寸的 40%，超过时等比缩小；细长配件保持原适配尺寸，画布缩放不影响规则。备注文字及备注图片在备注区域内水平居中。白色衬底及编号仍按缩放后的图片计算，画布与导出共用该规则。
未触发偏宽缩小的配件图增加 4 个画布单位顶部间距，白底与编号同步下移，属性布局预留相应空间；触发偏宽缩小的配件不增加该间距。
PDF 展开嵌入 SVG 前，先独立解析各图的样式、根变换及裁剪资源，再为每个实例生成独立 ID 前缀，防止不同产品和正反图的同名 clipPath/mask 相互引用。配件画布与导出均使用原始资源地址作为尺寸/裁剪缓存键，远程资源通过同一代理解析路径加载；离屏配件预加载失败时中止导出，禁止用未知尺寸静默输出。
