# 图片上传工作区

- `ProductCategoryNav` 展示当前批次的产品分类及全部选项，贴左侧排列，产品名完整换行。
- `UploadImageList` 按分类显示卡片，编号保持原批次位置，复选框与编号位于图片上方。预览按钮独立于选择；Ctrl 多选、Shift 在当前分类内连选，全选只作用于当前分类。
- `upload-workspace.css` 独立控制布局：1100px 两列、1400px 三列、1700px 及以上四列；右侧属性区域较窄，分类、图片列表、属性面板各自滚动。
- `ProductAttributesPanel` 管理已有产品、自定义产品与备注草稿。选中已有产品属性的图片时回填，选中空白图片时保留草稿，不提前写入图片资产。切换产品会清空产品附带字段，备注独立保留。
- “确认”位于备注下方。已有产品直接确认；自定义先存储产品预设，再调用相同的批次保存流程。保存进行中禁用重复确认；失败保留草稿和原资产，成功才提交资产状态。
- 新增资产字段 `attributesConfirmed`，Rust serde 默认 false 兼容旧批次；确认保存成功后为 true。卡片使用 Ant Design 默认灰色 / 蓝色 Tag 展示“未选产品” / “已选产品”。手动保存批次不会自动标记确认。
- 确认始终使用当前批次 ID，更新已有历史记录，不因属性变化另建记录。确认标记、备注、图片备注和属性一起写入 Rust 管理的本地数据库。
- 配置的产品、属性字段及选项值均按 `isHidden` / `hidden` / 删除标记 / editor 可见性过滤；确认时再次排除隐藏或无效联动值。当前缓存实测有 219 个隐藏字段和 1275 个隐藏选项值。

验证覆盖：两列/四列、分类筛选、全选范围、草稿继承与回填、已有/自定义切换、确认后历史请求与状态变化、保存失败不提交、隐藏字段和值过滤。浏览器使用模拟 Tauri 接口，不替代桌面文件选择器和 SQLite 的集成测试。
