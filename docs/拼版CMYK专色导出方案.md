# 拼版 CMYK 与专色独立导出

实现日期：2026-10-22。已接入导出窗口、原生转换、独立后台进程和文件提交，并完成四模式分色及真实板材验证。已追加 Photoshop 2020 的通道恢复兼容实现与实机验证；生产 RIP 仍需现场确认。

## 使用

导出 PDF 窗口右上角新增“导出 DXF”“导出 CMYK PDF”，默认都勾选，可以分别取消。普通 PDF、轮廓 DXF 和 CMYK PDF 为独立文件；每种重复版式只导出一次，沿用生产份数文件名。

- 普通 PDF：继续按轮廓、图片、彩窗、白墨顺序分页。
- DXF：从普通 PDF 的轮廓页来源生成，保留圆孔和毫米尺寸。
- 专色 PDF：`CMYK_<普通 PDF 文件名>.pdf`，每版式一页，同页包含九个墨版；不把墨版拆成九张灰度页。
- 只有线条、没有图片类型图层的版式不产生 CMYK 文件，普通 PDF / DXF 正常导出。

CMYK 设置包括双面同图 / 双面不同图、400 / 300 ppi、包含彩窗。在 SVG 图层类型下拉直接指定“图片正”“图片背”，第一个图片图层默认图片正，第二个默认图片背；不再额外选择正背来源。多个同面图层合并为一面，仍保持原始坐标。“应用到同名svg”同步这些类型。缺少正面或不同图模式缺少背面时指出 SVG 文件名。

同一 SVG 的所有 QT 使用共同产品参考框，保留原始局部关系。默认不按可见内容居中，避免小块彩窗被移到产品中心。可以开启“按可见区域居中对齐”，并通过叠加预览及背面 / 彩窗的 X、Y 毫米偏移校正。不自动镜像、不拉伸不同图案的可见边界。居中使用裁剪后的 alpha 边界，前端预览与原生转换使用相同工作分辨率。

## 四种模式

| 模式 | 过程 CMYK | White | C2 / M2 / Y2 / K2 |
| --- | --- | --- | --- |
| 双面同图 | 正面图片 | 图片透明度选区收缩 1 像素 | 正面 CMYK 的逐像素复制 |
| 双面不同图 | 正面图片 | 背面图片选区收缩 1 像素 | 背面 CMYK |
| 同图 + 彩窗 | 正面图片在独立彩窗层之上 | 加入彩窗之前的图片选区 | 两层可见合成后的 CMYK 复制 |
| 不同图 + 彩窗 | 正面图片在独立彩窗层之上 | 加入彩窗之前的背面选区 | 背面在独立彩窗层之上的可见 CMYK |

有彩窗的两种模式均先复制一份原彩窗，只将两份彩窗合并成底层“彩窗”；上层“图片”保留正面图片，彩窗不进入图片层像素。两层保持板材位置，整个板材所有 QT 分别合入对应的图片 / 彩窗层。无彩窗产品的图片也进入上层，不能因混排而丢失。Photoshop 直接打开时应显示“图片”“彩窗”两层，同时保留九个实际墨版。

两份半透明彩窗按 alpha 正常合成，不能把 CMYK 数值简单乘二。源图先恢复非预乘 RGB，再分别使用 ICC 转换，保留各层的直通 CMYK 和透明度；CMYK 合成主图及第二套四色只表示两层的可见效果，不替代独立图层。White 内部 100% 墨量，收缩使用 3×3 邻域的最小 alpha，保留镂空及抗锯齿边缘；彩窗不扩大白墨区域。

最终通道顺序为 `Cyan、Magenta、Yellow、Black、White、C2、M2、Y2、K2`。Photoshop 的 CMYK 复合预览不是额外墨版。五个专色的 solidity 为 1，White 替代显示色为黑，复制四色的替代显示色分别为纯 C / M / Y / K。

版面孔和 0.2 mm 外框进入 K 与 K2，White 不包含这些标记。普通轮廓 PDF 的孔仍为空心圆，其他普通 PDF 页面使用实心黑孔。

## 色彩与分辨率

- 默认 400 ppi，最低 300 ppi，不做静默降采样。尺寸取整到整数像素后仍使用原始毫米框放置。
- 收缩量为工作分辨率的 1 像素：400 ppi 为 0.0635 mm，300 ppi 为约 0.084667 mm。
- SVG 经 resvg 渲染成 sRGB，LittleCMS 2 使用相对比色转换到指定生产 ICC，当前未开启额外黑点补偿。
- 目标 ICC：`src-tauri/resources/color/250icm.icc`，内部名称 `250.icm`，4,324,768 字节，ICC 4.3、CMYK → Lab。
- 来源：`\\192.168.0.66\电商文件\公司员工\霍芃箔\250icm.icc`。
- SHA-256：`d3601f736c48c67ffcdfd75fc7b0977d7115619ece89f39194fac091cffae16a`。

ICC 编入程序，安装后不依赖共享目录在线。PDF 使用 DeviceN / NChannel 表达四过程色与五专色，嵌入输出 ICC，Flate 无损压缩（ZIP 路线），启用套印。同时写入页面 `PieceInfo / AdobePhotoshop`，包含独立生成的 `Alph` 专色描述、整板 CMYK 合成主图、五张反向灰度专色图和工作分辨率；有彩窗时再写入 `Layr` 图层像素块，否则仅有 Alph 会在 Photoshop 中恢复成一层背景。此兼容结构经 Photoshop 2020 对照测试，不依赖安装 Photoshop 才能导出。更多实证见 [Photoshop PDF 专色兼容性](Photoshop-PDF专色兼容性.md)。不同查看器对多专色模拟显示能力不同；例如当前 Poppler 对第五专色出现模拟限制提示。必须检查真实分色，不能仅依据屏幕预览判断生产墨量。PDF 不控制 RIP 的物理喷墨顺序。

## 实现与内存

前端 `impositionCmykExport.ts` 生成图层角色、参数和毫米放置，`impositionCmykPreview.ts` 生成按需对齐预览，`impositionPdfExportService.ts` 负责暂存、进度和批量导出。`imposition_cmyk.rs` 处理栅格、ICC、白墨和缓存，`imposition_cmyk_pdf.rs` 编码九色 PDF，`imposition_cmyk_photoshop.rs` 生成 Photoshop 可编辑的通道恢复数据；复用 `imposition_pdf_runtime.rs` 的 CPU / 内存调度与独立子进程。

每个原始 SVG + 实际尺寸 + 当前图层选择只转换一次，QT 副本通过 PDF XObject 和毫米变换复用。同图模式只转换一组 CMYK 后复制，不重复计算四色。按行合成、色彩转换和压缩。Photoshop 恢复数据逐个生成整板通道，原图通道只保留压缩缓存，QT 共享；四色由压缩流逐行交织，不创建整板九通道或四色未压缩缓冲。通道恢复数据会增加导出时间及文件体积，下面旧版计时不代表修复后的速度。

原图并行转换受全局 80% 逻辑处理器预算约束；根据 SVG 大小、像素数及实时可用内存限制批次，每批结束重新检查。图层 / 图片资源在原始顺序中合并，写文件和最终提交在父进程串行执行。内存不足明确报错，不降低 ppi。Windows Job 限制后台进程，进程崩溃不会带走主程序。

SVG 图层筛选后留下的空分组会扩大 usvg 的离屏裁剪层，尤其是原点在数千坐标以外的 Corel 文件。原生转换先去掉空分组，保留全部有效路径、裁剪、定义和图片；已经加入嵌套视口 / 高坐标裁剪回归测试。

导出阶段显示排队、原图资源、对齐、ICC 与白墨、压缩、合并和写入，并指出当前原图。CMYK 失败保留已完成的普通 PDF / DXF，指出文件名；临时文件在任务结束后释放。输出文件使用同目录临时文件和禁止覆盖的提交方式，避免留下半份成品或覆盖现有文件。

新增依赖：静态链接 `lcms2 6.1.1` / LittleCMS 2（MIT），`flate2`（MIT / Apache-2.0）；复用 resvg / usvg、tiny-skia、pdf-writer。

## Photoshop 通道兼容修复验收（2026-10-22）

旧版通用 DeviceN 文件在 Photoshop 2020 中只得到四个过程通道，故旧版 Ghostscript 分色验证不足以证明 Photoshop 兼容。新增独立的 Photoshop 恢复结构后，四种模式全部直接打开成功，顺序为 CMYK 复合项、青色、洋红、黄色、黑色、White、C2、M2、Y2、K2（面板共 10 行，实际 9 个墨版）。五专色均为 100% 密度；White 黑色预览，复制四色分别为纯 C、M、Y、K。

实际 Photoshop 再保存 PSD 后，逐个解码九个通道，与 PDF 恢复数据逐像素比较全部一致。同图复制四色与过程四色完全相同；不同图模式两套四色不同；加入彩窗不改变 White。Ghostscript tiffsep 仍可得到九个实际墨版。

真实版式 1（10 原图 / 28 放置）、版式 2（8 原图 / 22 放置）的 400 ppi 文件，以及版式 1 的 300 ppi 文件，均在 Photoshop 中恢复九个墨版、正确工作分辨率及 `250.icm`。原用户文档没有修改或关闭。

| 含通道恢复数据的开发构建 | 用时 | PDF MiB | 峰值工作集 MiB |
| --- | --- | --- | --- |
| 版式 1，400 ppi，4 工作者 | 42.83 秒 | 49.15 | 未完整采样 |

Photoshop 需要整板可编辑通道，因此比仅保存可复用 QT 资源的通用 PDF 更大、导出更慢；上表已经包含此成本。其内存通过单通道合成、压缩缓存、扫描行交织和既有后台进程限制控制，不同时展开九个整板。

可复查命令（需要本机 Photoshop，软件导出本身不需要）：

```powershell
./scripts/verify-cmyk-photoshop.ps1 -PdfPaths 'D:/export/CMYK_example.pdf'
```

此检查实际调用 Photoshop 打开文件，校验通道数、专色名称、顺序和密度，然后关闭测试文件、不保存修改，并恢复此前用户文档。详细私有结构依据和删减对照见 [Photoshop PDF 专色兼容性](Photoshop-PDF专色兼容性.md)。
