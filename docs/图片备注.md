# 图片备注

备注编辑位于图片属性面板底部，已有产品和自定义共用 `AssetNotesEditor`，支持文字与一张图片同时存在。编辑保留在表单草稿，点击下方“确认”才应用到当前选中的图片并保存批次；选择尚无产品属性的图片时保留上一项草稿，已有产品属性的图片会回填已保存信息。

资产使用独立字段 `note`（文字）与 `noteImage`（图片 data URL），不放入产品的 `attributes` 或 `attributeImages`。修改产品、QT、应用自定义产品均不清除备注。文字和图片可分别清空。

图片通过 Tauri 文件选择器和 Rust `import_custom_product_image` 读取。保存批次时由 Rust 序列化到本地数据库；旧记录通过 serde 默认值兼容。批次内容比较包含备注，防止新批次的不同备注被当成相同记录。

属性页签在图片选择或产品归属改变时自动定位；手动切换已有产品/自定义后，备注编辑不会再次强制切换页签。
