# 模块页面 UI 规范

以“生成示意图”的上传/最近使用记录页面为基准。示意图审核、生产拼版及后续新增业务模块使用同一套边距和文字层级，不另设一套页面布局数值。

## 尺寸与间距

| 项目 | 标准 |
| --- | --- |
| 页面距顶部导航、左右窗口及底部的距离 | 12px |
| 主内容卡片内边距 | 16px |
| 卡片 | 白色背景，1px `#e2e8f0` 边框，10px 圆角 |
| 页面背景 | `#f1f5f9` |
| 主标题 | 20px、700 字重，左对齐 |
| 标题与说明文字间距 | 8px |
| 说明文字 | 13px、`#64748b`，允许自然换行 |
| 标题区与筛选/内容区间距 | 26px |
| 筛选项间距 | 横向 16px，换行后纵向 12px |
| 筛选区与表格间距 | 16px |
| 表格单元格内边距 | 纵向 12px、横向 16px，保留 Ant Design 默认文字和控件尺寸 |
| 表格与底部统计/分页间距 | 16px |

标题、说明、筛选和表格沿卡片内侧统一左对齐。页面操作按钮放在标题区右侧；统计放左下，分页放右下。窄窗口中筛选项和底部分页自然换行，保持相同外边距，不挤压文字或控件。表格在自己的内容区滚动，避免挤出底部分页。

## 新模块接入

公共组件为 `src/components/ModulePage.tsx`，样式与设计变量为 `src/components/module-page.css`。新增常规业务页面应直接使用该组件，通过 `title`、`description`、`actions`、`toolbar`、`notice`、`footer` 放入业务内容；表格容器使用 `module-page-table`。

```tsx
<ModulePage
  title="模块名称"
  description="一句话说明这个页面的用途。"
  actions={<Button>刷新</Button>}
  toolbar={<Input placeholder="搜索" />}
  footer={<><span>共 20 条记录</span><Pagination total={20} /></>}
>
  <div className="module-page-table"><Table pagination={false} /></div>
</ModulePage>
```

模块自己的 CSS 只处理业务专属内容，例如审核日期筛选、状态背景色和附件明细，不覆盖公共组件的页面边距、卡片内边距或标题字号。以后调整全局规范时修改公共变量，而不是逐个页面增加覆盖规则。

生成示意图的多栏上传工作区也使用相同间距和标题变量；画布编辑器及产品分类侧栏保留自身专用布局。订单、订单图片编辑、生产进度的占位页已使用公共组件，后续实现页面时继续复用。
