# Finish 工艺匹配

保存批次（含确认生成排列页）时由 Rust 补全缺失的 Finish，并和图片属性一起持久化。已有非空 Finish 保留原值。

匹配使用本地 `printflow-data/cache/finish.json` 的 name、labelZh，忽略大小写、空白、连字符和下划线，以完整属性值匹配，写入标准 name。多项工艺去重后用 ` / ` 连接。产品名、数量、配件、配件颜色及图片字段不参与；图片内容与 URL 不参与。

进程内仅保留一个名称索引，文件修改时重建；保存阶段只遍历缺少 Finish 的图片属性，不传输或扫描 SVG 内容。不匹配的字段不写入虚假工艺。

排列组内部底端叠加单行文字，右对齐红色 10 号字，不换行、不缩字；不参与组高度、分页或排版占位计算；Konva 和导出 SVG 共用相同布局。同组相同工艺只展示一次。历史批次在下次保存/生成时补全。
