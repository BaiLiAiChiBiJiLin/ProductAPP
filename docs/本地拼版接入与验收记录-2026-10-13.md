# 本地拼版接入与验收记录（2026-10-13）

## 本次行为

1. 移除 CAD-N、pyFit 的拼版选项和专属适配/安装/冒烟脚本。项目本地缓存和已安装包的清理命令被自动审批拒绝，未执行；缓存不再被应用路由调用。
2. 默认选择“本地拼版（tools）”，真实调用本项目 `tools` 下的 Python 求解逻辑；只保留异形拼版。
3. “节省板材”逐板试排，比较单板放入数量及真实面积；“切割方案优先”以密排为基础，尝试 QT 配额、复用密集模板、再排余数。旧的每款一件数量层逻辑已移除。
4. 切割方案优先默认每种相同生产版式只画一块板，标注“需生产 N 块”。完整板材位置与 QT 均保留；展开全部实体板后可逐板编辑，重新计算后恢复折叠。
5. 删除拖动吸附，保留选择、跨板材移动和旋转。真实轮廓不得重叠、必须满足配置间距；完整旋转图片框不得越出有效区域。
6. 利用率改为真实轮廓面积 / 有效面积。QT 未修改时失焦或回车不再保存或重算。计算期间锁定会改变输入的控件，避免连续创建整单求解。

## 几何、内存与进度

- 所有输入输出尺寸与坐标均为毫米，Y 向下。放置坐标是完整图片旋转后外接框的左上角，保留 SVG 轮廓在原图内的偏移。
- Shapely 建立真实轮廓，OpenCV 在默认 0.5 mm 栅格上搜索，尝试 0–345°、步长 15°的旋转。完成后用 Shapely 再校验真实轮廓间距、图片框边界和 QT。
- 每个基础轮廓仅生成一次旋转掩码，QT 只是数量；同轮廓及图片尺寸共享缓存。重复板材共用轻量位置数组；输出时才生成每个副本的 ID 与位置。
- 缓存完整图片旋转框原点，避免为重复 QT 重新构造旋转几何。
- 单板占用只会增加，搜索记录每个旋转掩码的已排除位置，不重复扫描必然被挡的位置。小型差分回归验证与未缓存搜索逐位置一致；真实大批次仍以独立几何验收为准。
- 后端实时转发轮廓准备、模板/板材试排、剩余数量、校验进度。没有固定墙钟超时终止。
